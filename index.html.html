Latar Belakang

Mengapa sistem operasi, mengapa Linux, mengapa delapan buku

Sistem operasi: teori dan praktik

Sistem operasi adalah perangkat lunak yang mengelola sumber daya perangkat keras dan menyediakan layanan bagi program aplikasi.

  • Teori: proses dibuat dan dijadwalkan, memori dikelola, berkas disimpan, perangkat dikendalikan.
  • Praktik: sistem dipakai, dikonfigurasi, dan dirawat.
  • Menguasai satu sisi saja menyulitkan pemahaman utuh.

Mengapa Linux?

  • Kode sumber terbuka, rancangan internal dapat dipelajari.
  • Dipakai luas pada server, perangkat tertanam, dan komputasi awan.
  • Banyak buku dan panduan tersedia.

Mengapa membandingkan buku?

Banyaknya sumber membuat mahasiswa bingung: konsep, perintah dasar, administrasi sistem, atau membangun sistem dari nol?

Tujuan penulisan

  • Mengidentifikasi identitas lengkap tiap buku.
  • Merangkum isi tiap buku secara runtut.
  • Menganalisis kelebihan dan kekurangan.
  • Membandingkan tiga buku utama: cakupan, kedalaman, sasaran pembaca, kesesuaian dengan pembelajaran sistem operasi.
  • Memakai lima buku pendukung untuk menambah informasi dan memverifikasi sudut pandang.

Manfaat

  • Penulis: melatih membaca kritis dan menulis ilmiah.
  • Pembaca: panduan memilih rujukan (teori, penggunaan dan administrasi, jaringan, atau praktik membangun sistem).
  • Pengajar: bahan pertimbangan menyusun bahan ajar dan daftar bacaan.

Tiga lapisan: konsep dan kernel → penggunaan dan administrasi → jaringan dan layanan.

Bab II · Kajian Buku Utama Pertama

Operating Systems Foundations with Linux on the Raspberry Pi

Buku ajar yang mengikuti urutan topik teks sistem operasi, dengan Linux dan Raspberry Pi sebagai wahana

Bab 1–3 · Dasar dan perangkat keras

Model sistem berpusat pada memori; register, instruksi, bahasa rakitan, ALU, siklus instruksi, tumpukan, interupsi, DMA, cache, privilege, TLB. Praktik Linux: “everything is a file”, 5 tahap booting Raspberry Pi 3, modul kernel. Arm Cortex M0+ dan A53: MMU, cache L1/L2.

Bab 4–5 · Proses dan penjadwalan

/proc, hierarki proses, status, context switch, sinyal. Penjadwalan preemptive/non-preemptive, FCFS, round-robin, SJF, SRTF, prioritas, EDF; di Linux: nilai nice, Completely Fair Scheduler (CFS), real-time, red-black tree.

Bab 6–7 · Memori dan konkurensi

Memori fisik dan virtual, tabel halaman, over-commitment, pandangan proses atas memori. Konkurensi dan paralelisme beserta kerangka pemrograman paralel.

Bab 8–10 · I/O, penyimpanan, jaringan

Perangkat, penangan interupsi, I/O efisien. Filesystem, metadata, inode, FAT, reduksi latensi, perbaikan filesystem. Model OSI, tumpukan jaringan Linux, socket POSIX.

Bab 11 · Topik lanjutan

Sistem diperkecil/diperbesar, virtualisasi dan kontainerisasi, keamanan, verifikasi dan sertifikasi, rekonfigurabilitas, peta jalan Linux.

Perangkat belajar

Tiap bab: ringkasan, bacaan lanjutan, latihan dan pertanyaan; di akhir glosarium dan indeks.

Bab II · Kajian Buku Utama Kedua

Linux Fun

Panduan Linux sangat luas dalam tujuh bagian; penulis menyatakan buku belum selesai (ditulis Juni 2019–Januari 2020, bagian berguna sampai ±hal. 600)

I–III · Dasar dan shell

Sejarah, distribusi, instalasi, direktori, berkas, man page (Bab 1–9). Shell: variabel, globbing, redireksi, filter, regex (Bab 10–20). Editor vi dan skrip, perulangan, parameter (Bab 21–26).

IV · Pengguna, proses, perangkat lunak

Pengguna, kata sandi, grup, izin berkas, ACL, link, proses, sinyal, jobs, prioritas, manajemen perangkat lunak (Bab 27–42).

V · Penyimpanan

Partisi, filesystem, mounting, UUID, RAID, LVM, ZFS, multipath (Bab 43–54).

VI · Administrasi, jaringan, server

Booting, penjadwalan tugas, log, memori, TCP/IP, SSH, NFS, routing, kernel dan modul, pencadangan, waktu (Bab 55–79). Bagian VII: Xen, DHCP, DNS (Bab 80–82).

Latihan dan praktik

Sebagian besar bab diakhiri latihan (practice) beserta jawaban (solution); beberapa bab memiliki cheat sheet. Disebarkan gratis lewat linux-training.be.

Bab II · Kajian Buku Utama Ketiga

Linux Networking

Paul Cobbaut · untuk pelatihan dipandu instruktur, sasaran administrator sistem Linux pemula; dibaca sambil mengoperasikan komputer Linux

Bagian I · Manajemen jaringan

Konfigurasi antarmuka, network sniffing, binding dan bonding, klien/server SSH, pengantar NFS (Bab 1–7).

II · Web dan proxy

Server web Apache dan proxy Squid (Bab 8–9).

III–IV · DNS dan DHCP

DNS dari pengantar hingga lanjutan (Bab 10–11); server DHCP (Bab 12).

V · Router dan firewall

Routing dan firewall iptables (Bab 13–14).

VI · Samba (Bab 15–24)

Bagian terpanjang: server berkas read-only dan writable, autentikasi, pengamanan share, domain member dan domain controller, tinjauan singkat Samba 4.

VII–VIII · IPv6

Pengantar IPv6 (Bab 25) dan lampiran. Fokus: Linux untuk administrasi jaringan.

Kontribusi Buku Pendukung

Dikelompokkan menurut fokus, melengkapi tiga buku utama

Dasar penggunaan

Introduction to Linux — 11 bab: quickstart, berkas, proses, redireksi I/O, editor, /home, pencetakan, pencadangan, jaringan, suara dan video; tiap bab berlatihan.

Administrasi

Membangun sistem

Catatan cepat

Bab III · Analisis Kritis Buku Pertama

Operating Systems Foundations

Vanderbauwhede dan Singer (2019)

Kelebihan

  • Sesuai kurikulum: urutan bab lazim; ada ringkasan, latihan, glosarium, indeks.
  • Teori ↔ implementasi: dari FCFS/round-robin ke CFS, nice, real-time, red-black tree; memori virtual dikaitkan dengan MMU dan TLB Cortex A53.
  • Praktik terjangkau: Raspbian, SSH, modul kernel, bangun kernel.
  • Topik lanjutan: virtualisasi, kontainerisasi, keamanan, verifikasi.

Kekurangan

  • Terikat Arm dan Raspberry Pi 3; pengguna x86 menerjemahkan contoh sendiri.
  • Hampir seluruhnya Linux; tanpa perbandingan sistematis dengan Windows/macOS.
  • Bahasa rakitan, struktur data kernel, modul kernel menuntut bekal pemrograman.
  • Kemutakhiran: setahu penulis, sejak kernel 6.6 CFS digantikan EEVDF; Raspberry Pi 3 sudah digantikan.

Kedalaman teori: tinggi. Konsep tetap berlaku, detail implementasi perlu diperiksa terhadap versi kernel.

Bab III · Analisis Kritis Buku Kedua dan Ketiga

Linux Fun dan Linux Networking

Cobbaut (2021) dan Cobbaut (2015)

Linux Fun — kelebihan

  • Cakupan luas dan bertahap (>80 bab): perintah → skrip → administrasi.
  • Latihan dan jawaban, cheat sheet.
  • Penyimpanan mendalam: UUID, RAID, LVM, ZFS, multipath.
  • Gratis dan boleh dibagikan.

Kekurangan

  • Belum selesai: draf setelah ±hal. 600; Bagian VII (Xen, DHCP, DNS, hal. 651) belum matang.
  • Bukan teori OS: memori hanya ±8 hal. (498–506).
  • ±700 hal.; tumpang tindih dengan Linux Networking (SSH, NFS, DHCP, DNS); tanpa penerbit formal.

Linux Networking — kelebihan

  • Fokus pada layanan jaringan administrator.
  • Samba 10 bab, dari read-only hingga domain controller.
  • Praktis, dibaca bersama komputer; tersusun per layanan; lisensi GNU FDL.

Kekurangan

  • Terbit 2015; Samba 4 hanya satu bab tinjauan (Bab 24).
  • IPv6 satu bab di akhir, mayoritas IPv4.
  • Tidak membahas proses, penjadwalan, memori.
  • Untuk administrator pemula yang sudah bisa shell.

Bab IV · Saran dan Rekomendasi

Mulai dari buku konsep; berlatih dengan Linux Fun atau The Linux Command Line; buka Linux Networking bila perlu layanan jaringan; verifikasi detail kritis ke dokumentasi resmi.

Selesaikan bagian draf; perbarui topik yang berubah (penjadwal kernel, Samba 4, IPv6).
